# 🛵 Honda Activa 6G — QR Contact Page

A modern, mobile-first personal contact webpage created for a **Honda Activa 6G**.

The webpage is designed to be accessed through a **QR code attached to the scooter**. If someone finds an issue with the scooter, needs to inform the owner, notices damage, or simply needs to contact the owner, they can scan the QR code and immediately access the available contact options.

---

* 📱 Mobile-first responsive design
* 🛵 Honda Activa 6G vehicle information

* 🔧 Report a scooter issue

---

## 🎯 Purpose

This website is intended to provide an easy way for someone who encounters the scooter to contact its owner.

The QR code can be printed and placed somewhere appropriate on the scooter. When scanned, it opens this webpage and provides direct communication options.

### Typical use cases

Someone can use the page to:

* Inform the owner about a problem with the scooter.
* Report possible damage.
* Notify the owner about a parking or obstruction issue.
* Provide important information about the scooter.
* Contact the owner for another scooter-related matter.

## 📲 Contact Options

The webpage includes:

Uses the device's standard `tel:` functionality to open the phone/calling application.

### 💬 WhatsApp

Opens WhatsApp with a pre-filled message containing the scooter identification.

### ✉️ Email

Opens the user's configured email application with a pre-filled subject.

### 🔧 Report an Issue

Allows a visitor to quickly contact the owner if they notice a problem with the scooter.

### 🅿️ Parking / Obstruction

Provides a dedicated communication option for parking-related situations.

### ⚠️ Damage / Incident

Allows someone to notify the owner about possible damage or an incident involving the scooter.

## 🚀 Deployment

This project can be deployed using any static website hosting service.

For example:

* GitHub Pages
* Netlify
* Vercel
* Other static hosting platforms

### GitHub Pages

1. Upload `index.html`, `style.css`, and `README.md` to the repository.
2. Open the repository's **Settings**.
3. Go to **Pages**.
4. Select the appropriate branch as the deployment source.
5. Save the settings.
6. GitHub will provide the website URL.

The generated URL can then be converted into a QR code.

## 🔒 Privacy

This is a publicly accessible webpage, so only basic information necessary for contacting the owner should be displayed.

The website should **not** contain sensitive information such as:

* Aadhaar number
* PAN number
* Driving licence number
* Home address
* Bank information
* Insurance policy numbers
* Other confidential personal information

The contact information displayed on the website should be used responsibly and only for legitimate communication regarding the scooter.
